## 4. Global Audit Findings

Severity: **C** = Critical, **H** = High, **M** = Medium, **L** = Low.

### 4.1 Backend — Security & Architecture

| # | Sev | Finding | Evidence / Impact | Fix |
|---|---|---|---|---|
| 4.1.1 | C | **Tenant IDOR:** several controllers use the URL `:id` for org lookups while multi-tenancy is enforced via `X-Organization-Id`, so a caller can pass another org's `:id` and read/write data they don't own | cross-org data access; the proven-correct pattern exists (`TenancyGuard`/`@OrganizationId()`) but is not applied uniformly | Derive the org always from `X-Organization-Id`; treat URL org id as display-only or remove it; add authz tests per module |
| 4.1.2 | C | **Hardcoded secrets in `services/api/.env`** (e.g. `AI_ENCRYPTION_KEY`, JWT secrets) | if repo is committed/hosted, secrets leak | move to secret manager/K8s Secret/.env outside repo; rotate now; add committed `.env.example` only |
| 4.1.3 | H | **No auth rate limiting / brute-force protection** on login/register/refresh | credential stuffing | add in-memory token bucket now, Redis-backed `@nestjs/throttler` in prod |
| 4.1.4 | H | **Input validation gaps in dev/scan area** — SSRF-ish (arbitrary repo URLs), shell command injection risk in git exec, file path traversal | code-analysis endpoints could hit internal hosts or execute arbitrary commands | strict allowlists, `child_process` arg arrays (never `-c`), URL host allowlisting, sandboxed runners |
| 4.1.5 | H | **No automated tests** for the API (0 spec files) | regressions on critical money/tenant paths are silent | start with payroll + auth + org-scoping tests (Vitest+Supertest against the exact CI Postgres) |
| 4.1.6 | M | **`start:prod` path is wrong** — uses `dist/main.js`, the build emits `dist/src/main.js` | prod boots fail immediately | fix package.json script; add a container healthcheck that hits `/api/health` |
| 4.1.7 | M | **N+1 / heavy Prisma queries** in list endpoints (users, tasks, dev issues) | slow lists as orgs grow | `include`/`select` shaping, cursor pagination, composite `(org_id, …)` indexes on high-volume reads |
| 4.1.8 | M | **Payroll money handled as integers** (gross/net in units) — fine, but rates/bonuses have no DB-level decimal type and no audit trail re-computes | drift possible without an AuditLog write | persist an immutable `payroll_history` snapshot keyed by run+entry; write an audit log entry on generate/override/mark-paid |
| 4.1.9 | M | **JWT/refresh** — verify refresh rotation, expiry, and device revocation exist; session invalidation on role change | stale privileges after role downgrade | hard-require: reject rotated refresh tokens, bump token `iat` on role/org change |
| 4.1.10 | L | Websocket/notification services run unauthenticated in dev and have no auth handshake on rooms | cross-org live updates in dev | enforce JWT + org-room membership server-side in both services; add tests |

| 4.2.1 | M | **i18n is one 3,800-line file** with all 3 locales — merge/typo/leak risk, brittle to use | split per-locale modules at build time (e.g. `ar.ts`, `en.ts`, `fr.ts`) with a type-completion check; keep a CI lint that asserts identical key sets |

## 5. Hosting & Scalability Plan (3 tiers, with cost figures)

Prices are **approximate monthly estimates** (2026, region: `eu-central-1`/`me-south-1` or compare a regional VPS). Numbers assume on-demand; savings plans / committed use cut EC2/Fargate/RDS costs ~30–40%.

### Tier 1 — Bootstrap / MVP (~$25–45/mo)
For demoing to customers; one box, acceptable behind a cloud firewall.

| Item | Spec | est. $/mo |
|---|---|---|
| VPS (Hetzner/Contabo/DO) | 4 vCPU, 8 GB, 160 GB NVMe | 20–40 |
| Domains + DNS | Route53 / registrar | 1–2 |
| TLS | Let's Encrypt auto-renew | 0 |
| **Total** | | **~25–45** |

- Run the full stack via compose/Docker or systemd; Postgres on-box with nightly `pg_dump` to offsite storage.
- Ceiling: ~100 orgs / ~15k rows per high-volume table before it stops being pleasant.

### Tier 2 — Managed production SaaS (~$150–200/mo)
For 1–5k orgs, ~10–50 RPS. The recommended steady state.

| Item | Spec (region eu-central-1/me-south-1) | est. $/mo |
|---|---|---|
| Web (Next.js) | ECS Fargate, 2 tasks × 0.5 vCPU/1 GB | 40 |
| API (NestJS) | ECS Fargate, 2 tasks × 0.5 vCPU/1 GB | 45 |
| Gateway/WS/Notify/AI | Fargate, 4 × 0.25 vCPU/0.5 GB | 30 |
| Postgres | RDS `db.t4g.small`, 20 GB gp3 | 18 |
| Redis | ElastiCache `cache.t4g.micro` | 14 |
| Load balancer | ALB + minimal LCUs | 20 |
| Logs/monitoring | CloudWatch + S3 (images/attachments/backups) | 15 |
| Route53 | 2 zones | 1 |
| **Total** | | **~185** |

Triggers to scale (monolith is fine here): API CPU >70% sustained, p95 >250 ms, DB connections >50%.

### Tier 3 — Scale / dedicated-tenant (~$550–700/mo)
For 5k+ orgs, higher traffic, multi-AZ + autoscaling; extract services as documented in ADR-001.

| Item | Spec | est. $/mo |
|---|---|---|
| EKS control plane | managed, 1 cluster | 75 |
| Workers | 3–4 × `m6i.large` (multi-AZ) | 210–280 |
| Postgres | RDS `db.r6g.large` multi-AZ + 1 replica | 150–180 |
| Redis cluster | ElastiCache 2 shards | 60 |
| ALB | heavier LCUs | 35 |
| Observability | Grafana/CloudWatch, tracing | 25 |
| Egress/storage | S3 + NAT/egress | 25 |
| **Total** | | **~580–680** |

Scale levers: horizontal HPA on API/web, offload analysis to worker pool, partition `dev_issues`/`messages`/`audit_logs` by org, read replicas for dashboards, caching in Redis, presigned-URL object storage.

**Recommendation:** ship Tier 1 now, move to Tier 2 at first revenue, never hand-roll Tier 3 — require the CI + Terraform to create it.

## 6. Target CI/CD Pipeline

Current CI (`ci.yml`) only checks: cargo fmt+clippy+test, go build+vet, api typecheck, web build. Add:

1. **Test** (already passing): provision Postgres 15 + Redis in CI; add `api` Jest/Vitest suite.

3. **Deploy:** on push to `main`: `staging` (compose or ECS/Fargate); on tag `v*`: `production` with a manual approval.
4. **Quality gates:** secrets scan (gitleaks), `npm audit`/`cargo audit`, tsc + eslint, and a contract test that `techdebt-platform`'s typed API client stays in sync with Swagger (generate types from `/api/docs-json`).
